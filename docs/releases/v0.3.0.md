The repository version is `0.3.0`. Component versions remain independent; Doctor and Baseline do not need numerically identical versions. Compatibility is determined by the explicit Doctor schema/scanner contract consumed by the Baseline verifier.

## Highlights

- Adds the separately invocable Unity Baseline Verification Skill to the released repository baseline.
- Freezes the Doctor `0.2.1` / schema `1.1.0` fingerprint handoff required by Baseline `0.1.2`.
- Separates original copy-set integrity from Git metadata integrity.
- Treats only newly added Codex checkpoint paths in the exact allowed namespace as ambient metadata.
- Continues to block changed HEAD, index, config, hooks, ordinary refs, objects, source content, and disallowed Git paths.
- Keeps both Skills at `allow_implicit_invocation=false`.

## Safety and scope

- Doctor remains a fully read-only static audit and never starts Unity.
- Baseline starts Unity only in an external isolated copy after explicit invocation and strict preflight checks.
- Neither Skill installs packages, modifies the source project, performs automatic repair, runs tests, creates a Player Build, verifies PlayMode/runtime, or silently elevates unverified evidence.
- Raw acceptance output is not committed because it contains machine-local absolute paths.
