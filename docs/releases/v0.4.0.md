## Safety and scope

- Doctor remains a fully read-only static audit and never starts Unity.
- The Baseline orchestrator does not start Unity or Unity Hub. Only the low-level verifier may start the trusted editor after all required preflight checks pass.
- Unity receives only an external isolated copy, never the original project path.
- Artifacts, logs, and copied project data remain outside the original project.
- No package, PowerShell module, Unity version, certificate bundle, or other external dependency is installed.
- Neither Skill performs automatic repair, cleanup, rollback, test execution, Player Build, PlayMode, gameplay, or runtime verification.
- No unverified result is promoted to success, and inconclusive live-process evidence remains fail-closed.
